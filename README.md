# Lexicon — 영단어 플래시카드

탭해서 뒤집는 플래시카드 + SM-2 간격 반복. 브라우저에만 저장되고 서버가 없습니다.

## 배포 (5분)

1. GitHub에서 새 저장소를 만듭니다. 이름은 아무거나 (예: `lexicon`). **Public** 으로 만드세요.
2. 이 폴더의 파일 6개를 저장소 최상단에 올립니다.
   - `index.html`
   - `sw.js`
   - `manifest.webmanifest`
   - `icon-192.png`
   - `icon-512.png`
   - `icon-512-maskable.png`
3. 저장소 → **Settings** → **Pages** → Source 를 `Deploy from a branch`, Branch 를 `main` / `/ (root)` 로 두고 Save.
4. 1~2분 뒤 `https://<아이디>.github.io/lexicon/` 로 열립니다.

## 홈 화면에 추가

- **iPhone**: Safari로 접속 → 공유 버튼 → "홈 화면에 추가"
- **Android**: Chrome으로 접속 → 메뉴 → "앱 설치" 또는 "홈 화면에 추가"

한 번 열어두면 이후에는 인터넷 없이도 열립니다.

## 단어 넣기

**사전 탭에서 찾아 담기** — 아무 설정 없이 바로 됩니다. 단어나 숙어를 적고 찾으면
영어 뜻과 예문이 나오고, 마음에 드는 뜻 옆의 `+` 를 누르면 카드가 됩니다.
영어 뜻은 위키낱말사전 원문이고 한국어는 기계 번역이라, 담은 카드에는 "확인 필요" 표시가 붙습니다.

**한꺼번에 넣기** — 단어 탭에 영단어만 한 줄에 하나씩 붙여넣으면 됩니다.
뜻까지 채우려면 "Claude용 프롬프트 복사"를 누르고 Claude에 붙여넣은 뒤,
받은 CSV를 다시 같은 칸에 붙여넣으세요.

직접 넣을 때 열 순서: `단어,뜻,예문,연어,태그` (태그 여러 개는 `;` 로 구분)

## 폰과 PC 함께 쓰기 (권장)

설정 → 데이터 에서 GitHub 토큰을 한 번 넣으면 두 기기가 같은 데이터를 보게 됩니다.

**토큰 만들기**
1. github.com → 프로필 → Settings
2. 맨 아래 Developer settings → Personal access tokens → **Tokens (classic)**
3. Generate new token (classic) → 이름 아무거나 → 권한은 **gist 하나만** 체크
4. Generate token → 나온 문자열 복사 (그 화면을 벗어나면 다시 볼 수 없습니다)

앱 설정에 붙여넣고 "연결하기"를 누르면 비공개 Gist가 자동으로 만들어집니다.
**다른 기기에서도 같은 토큰을 넣으면** 그 Gist를 찾아서 데이터를 그대로 이어받습니다.

이후에는 단어를 추가하거나 채점할 때 잠시 뒤 자동으로 올라가고, 앱을 열 때 자동으로 받아옵니다.
양쪽에서 따로 공부해도 합쳐집니다 — 같은 날 폰에서 30장, PC에서 20장을 했으면 50장으로 더해집니다.
겹치는 단어는 더 나중에 공부한 쪽 기록이 남습니다.

**데이터를 아끼려면** 같은 화면의 "데이터 아껴 쓰기"를 켜세요. 자동 동기화 간격이 1분으로
늘고, 앱으로 돌아올 때 자동으로 받아오지 않습니다. 바뀐 게 없으면 어차피 거의 주고받지
않으므로(변경 여부만 확인) 평소에는 꺼도 됩니다.

토큰 권한을 gist 하나로 좁혔으므로 새더라도 이 단어장 외에는 영향이 없습니다.
기기를 잃어버리면 GitHub의 같은 화면에서 토큰을 Revoke 하세요.

## 파일로 백업

설정 → 데이터 → 파일로 주고받기 에서 `.json` 하나로 내보내고 불러올 수 있습니다.
동기화를 쓰면 평소엔 필요 없지만, 토큰이 막히거나 Gist가 사라졌을 때 되살릴 수단으로 남겨 뒀습니다.

## 팩으로 정리하기

단어를 넣을 때 팩 이름을 `/` 로 나누면 폴더처럼 정리됩니다.

```
영 쉘던/S1/E01
영 쉘던/S1/E02
영 쉘던/S2/E01
TOEIC/파트5
```

팩 탭에서 파고들어가면 그 범위의 단어가 **많이 틀린 순서**로 나옵니다.
각 팩에서 "이 팩 복습"(일정 반영) 또는 "전체 훑기"(일정 영향 없음)를 할 수 있습니다.

## 학습량이 너무 늘어날 때

하루 복습량은 **신규 단어 수**가 결정합니다. 신규 15개/일이면 몇 달 뒤 하루 100~150장에서 균형을 잡습니다.

Anki와 똑같이 조절 장치는 둘뿐입니다.

- **하루 신규 단어** (기본 15) — 앞으로의 복습량을 정하는 값입니다. 밀리면 여기부터 줄이세요.
- **하루 최대 복습** (기본 100) — 초과분은 다음 날로 넘어갑니다. 밀린 것부터 먼저 나옵니다.

세션을 몇 장으로 끊을지는 Anki에 없어서 두지 않았습니다. 오늘 몫을 한 번에 내주고,
중간에 그만두면 거기까지가 오늘 한 것입니다. 채점은 카드마다 저장되니 끊어서 해도 됩니다.

8번 이상 틀린 단어에는 **누수 단어** 표시가 붙습니다. 대개 카드가 나쁜 것이라 고치는 게 빠릅니다.

상한은 일을 미룰 뿐 줄이지 않습니다. 계속 밀리면 하루 신규 단어를 먼저 줄이세요.

## 알아둘 것

- 데이터는 브라우저 localStorage 에 있습니다. 브라우저 데이터를 지우면 같이 사라지니 가끔 백업하세요.
- 시크릿/프라이빗 모드에서는 저장되지 않습니다.
- 음성은 기기에 설치된 것을 씁니다. 인터넷 데이터는 쓰지 않습니다.
  **영어 음성이 설치되어 있지 않으면 한국어 음성이 영어를 읽어서 발음이 어색합니다.**
  설정 → 문제 형식과 발음 에 설치 안내가 뜹니다. iOS는 자동 재생이 막힐 수 있습니다.
- 저장소를 Public 으로 두면 코드는 공개되지만 **단어와 학습 기록은 올라가지 않습니다.** 전부 각자 브라우저에만 있습니다.
- 사전 검색은 **키 없이 기본으로 동작합니다.** 더 자연스러운 한국어 뜻을 원하면 설정에서
  Gemini 무료 키를 넣을 수 있고, Anthropic 키는 사용료가 별도로 과금되니 필요할 때만 쓰세요.
- 사전을 쓰면 단어가 위키낱말사전과 번역 서비스로 전송됩니다. 영단어 하나뿐이지만 알고 쓰세요.
