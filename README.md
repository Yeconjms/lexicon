# Lexicon — 영단어 플래시카드

탭해서 뒤집는 플래시카드 + SM-2 간격 반복. 브라우저에만 저장되고 서버가 없습니다.

## 배포 (5분)

1. GitHub에서 새 저장소를 만듭니다. 이름은 아무거나 (예: `lexicon`). **Public** 으로 만드세요.
2. 이 폴더의 파일 6개를 저장소 최상단에 올립니다.
   - `index.html`
   - `sw.js`
   - `manifest.webmanifest`
   - `icon-192.png`
   - `icon-512.png`
   - `icon-512-maskable.png`
3. 저장소 → **Settings** → **Pages** → Source 를 `Deploy from a branch`, Branch 를 `main` / `/ (root)` 로 두고 Save.
4. 1~2분 뒤 `https://<아이디>.github.io/lexicon/` 로 열립니다.

## 홈 화면에 추가

- **iPhone**: Safari로 접속 → 공유 버튼 → "홈 화면에 추가"
- **Android**: Chrome으로 접속 → 메뉴 → "앱 설치" 또는 "홈 화면에 추가"

한 번 열어두면 이후에는 인터넷 없이도 열립니다.

## 단어 넣기

**사전 탭에서 찾아 담기** — 아무 설정 없이 바로 됩니다. 단어나 숙어를 적고 찾으면
영어 뜻과 예문이 나오고, 마음에 드는 뜻 옆의 `+` 를 누르면 카드가 됩니다.
영어 뜻은 위키낱말사전 원문이고 한국어는 기계 번역이라, 담은 카드에는 "확인 필요" 표시가 붙습니다.

**한꺼번에 넣기** — 단어 탭에서 세 가지 방법이 있습니다.

1. **붙여넣기** — 영단어만 한 줄에 하나씩 넣어도 되고, 아래 CSV 형식으로 넣어도 됩니다.
2. **파일에서 넣기** — `.csv` `.tsv` `.txt` 파일을 고르면 바로 읽습니다.
   엑셀에서 저장한 한국어 파일(EUC-KR)도 알아서 처리합니다.
   팩 탭에서 **CSV로 넣기** 를 누르면 그 팩으로 바로 들어갑니다.
   같은 화면의 **CSV로 내보내기** 로 받은 파일은 그대로 다시 넣을 수 있습니다.
3. **AI로 정리해서 넣기** — 아래 설명을 보세요.

### 정리 안 된 메모를 AI로 바꾸기

드라마 보면서 대충 적어둔 메모라도 됩니다. 순서는 이렇습니다.

1. 단어 탭에서 **"Claude용 프롬프트 복사"** 를 누릅니다.
2. Claude(또는 ChatGPT, Gemini) 대화창에 붙여넣습니다.
3. 그 **아래에 메모를 그대로 붙여넣고** 보냅니다. 번호, 하이픈, 날짜가 섞여 있어도 됩니다.
4. 받은 CSV를 복사해서 단어 탭 입력칸에 붙여넣고 **확인하기 → 추가**.

프롬프트가 AI에게 시키는 일은 이렇습니다.

- 변형형을 기본형으로 (ran → run), 숙어는 그대로 (put up with)
- 뜻은 문장이 아니라 사전처럼 짧게, 1~3개를 `/` 로 구분
- 메모에 그 단어가 든 문장이 있으면 그걸 예문으로 쓰고, 없으면 하나 만들기
- 같은 단어가 여러 번 나오면 한 줄로 합치기
- 영어 단어가 아닌 줄(제목, 날짜, 메모)은 버리기

### CSV 열 순서

```
단어,뜻,예문,함께쓰는표현,태그,팩
```

| 열 | 무엇을 넣나 |
|---|---|
| 단어 | 영단어나 숙어 |
| 뜻 | 한국어 뜻. 여러 개면 `/` 로 구분 |
| 예문 | 그 단어가 들어간 영어 문장 |
| 함께쓰는표현 | 그 단어가 보통 어떤 말과 붙어 다니는지. 여러 개면 `;` 로 구분 |
| 태그 | 주제 표시. 여러 개면 `;` 로 구분 |
| 팩 | 어디서 모았는지. `/` 로 계층 (`영 쉘던/S1/E02`) |
| 비슷한말 | 뜻이 가까운 영어 단어. 여러 개면 `,` 로 구분 |
| 반대말 | 뜻이 반대인 영어 단어. 여러 개면 `,` 로 구분 |

**단어와 뜻만 있으면 됩니다.** 뒤쪽 열은 비워도 되고 아예 빼도 됩니다.
쉼표가 들어가는 칸은 큰따옴표로 감싸세요. 첫 줄이 머리글이면 알아서 건너뜁니다.

## 폰과 PC 함께 쓰기

**로그인하면 됩니다.** 이메일과 비밀번호로 가입하면 단어장이 계정에 저장되고,
다른 기기에서 같은 계정으로 들어가면 그대로 이어집니다.

로그인을 쓰려면 먼저 Firebase 설정이 필요합니다. [FIREBASE.md](FIREBASE.md) 를 보세요.
설정 전에는 로그인 화면 없이 이 기기에서만 쓰는 상태로 동작합니다.

계정 없이 쓰다가 나중에 로그인해도 됩니다. 그때까지 모은 단어를 계정으로 옮겨 줍니다.

## 파일로 백업

설정 → 데이터 → 파일로 주고받기 에서 `.json` 하나로 내보내고 불러올 수 있습니다.
동기화를 쓰면 평소엔 필요 없지만, 토큰이 막히거나 Gist가 사라졌을 때 되살릴 수단으로 남겨 뒀습니다.

## 팩으로 정리하기

단어를 넣을 때 팩 이름을 `/` 로 나누면 폴더처럼 정리됩니다.

```
영 쉘던/S1/E01
영 쉘던/S1/E02
영 쉘던/S2/E01
TOEIC/파트5
```

팩마다 **색과 아이콘**을 고를 수 있습니다. 팩 안으로 들어가 "색과 아이콘" 을 펼치면 됩니다.
하위 팩은 비워 두면 위 팩의 것을 물려받습니다. `영 쉘던` 에만 지정하면 그 아래 회차가 전부 같은 색이 됩니다.

팩 탭에서 파고들어가면 그 범위의 단어가 **많이 틀린 순서**로 나옵니다.
각 팩에서 "이 팩 복습"(일정 반영) 또는 "전체 훑기"(일정 영향 없음)를 할 수 있습니다.

## 학습량이 너무 늘어날 때

하루 복습량은 **신규 단어 수**가 결정합니다. 신규 15개/일이면 몇 달 뒤 하루 100~150장에서 균형을 잡습니다.

Anki와 똑같이 조절 장치는 둘뿐입니다.

- **하루 신규 단어** (기본 15) — 앞으로의 복습량을 정하는 값입니다. 밀리면 여기부터 줄이세요.
- **하루 최대 복습** (기본 100) — 초과분은 다음 날로 넘어갑니다. 밀린 것부터 먼저 나옵니다.

세션을 몇 장으로 끊을지는 Anki에 없어서 두지 않았습니다. 오늘 몫을 한 번에 내주고,
중간에 그만두면 거기까지가 오늘 한 것입니다. 채점은 카드마다 저장되니 끊어서 해도 됩니다.

8번 이상 틀린 단어에는 **누수 단어** 표시가 붙습니다. 대개 카드가 나쁜 것이라 고치는 게 빠릅니다.

상한은 일을 미룰 뿐 줄이지 않습니다. 계속 밀리면 하루 신규 단어를 먼저 줄이세요.

## 통계 탭의 별

복습 상태에 따라 마스코트 별의 표정이 바뀝니다.

| 상태 | 별 |
|---|---|
| 7일 이상 연속 + 오늘 몫 완료 | 활짝 웃으며 들썩임 |
| 오늘 몫 완료 / 3일 이상 연속 | 웃는 얼굴에 반짝임 |
| 아직 안 함 | 자는 얼굴 |
| 밀린 카드 50장 이상 | 화난 얼굴로 부들부들 |
| 밀린 카드 120장 이상 | 터지기 직전 |

**사흘 이어갈 때마다 작은 별이 하나씩 늘어납니다.** 최대 다섯 개까지 붙습니다.

## 알아둘 것

- 데이터는 브라우저 localStorage 에 있습니다. 브라우저 데이터를 지우면 같이 사라지니 가끔 백업하세요.
- 시크릿/프라이빗 모드에서는 저장되지 않습니다.
- 음성은 기기에 설치된 것을 씁니다. 인터넷 데이터는 쓰지 않습니다.
  **영어 음성이 설치되어 있지 않으면 한국어 음성이 영어를 읽어서 발음이 어색합니다.**
  설정 → 문제 형식과 발음 에 설치 안내가 뜹니다. iOS는 자동 재생이 막힐 수 있습니다.
- 저장소를 Public 으로 두면 코드는 공개되지만 **단어와 학습 기록은 올라가지 않습니다.** 전부 각자 브라우저에만 있습니다.
- 사전 검색은 **키 없이 기본으로 동작합니다.** 더 자연스러운 한국어 뜻을 원하면 설정에서
  Gemini 무료 키를 넣을 수 있고, Anthropic 키는 사용료가 별도로 과금되니 필요할 때만 쓰세요.
- 사전을 쓰면 단어가 위키낱말사전과 번역 서비스로 전송됩니다. 영단어 하나뿐이지만 알고 쓰세요.
